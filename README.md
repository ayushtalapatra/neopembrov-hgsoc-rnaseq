# NeoPembrOV HGSOC RNA-seq Analysis

Transcriptomic analysis of the NeoPembrOV clinical trial dataset (GSE227666)

## Research Question
Why does pembrolizumab fail to improve survival in high-grade serous ovarian carcinoma?

## Key Finding
Broad suppression of immune activation pathways in post-treatment tumors from patients receiving pembrolizumab plus chemotherapy versus chemotherapy alone

## Data
GEO Accession: GSE227666

## Tools
Python, PyDESeq2, GSEApy, Pandas, NumPy, Matplotlib, Seaborn
